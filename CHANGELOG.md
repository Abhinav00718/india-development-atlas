# Changelog

This changelog records the main application capabilities established during development. It is a high-level project history, not a claim that every data value has been independently verified.

## Current documented version

- Interactive Development Map using the repository's GeoJSON boundaries.
- Neutral display for regions where the selected indicator has no usable observation.
- Separate handling intended to keep island territories visible when indicator data is missing.
- State Rankings with ordering, region-type filters, missing-data reporting, and CSV export.
- Explore a Region page.
- Compare Regions page.
- Economic Relationships Lab with selectable indicators, scatter plot, correlation, fitted linear trend, and downloadable relationship data.
- Data Quality & Coverage page with region-indicator coverage and missing/reference-year information.
- About & Sources page.
- Indicator-specific CSV files, including per-capita power availability.
- Data Explorer page removed from navigation.
- Duplicate Economic Relationships Lab navigation entry removed.

## Stability policy

Preserve the current working application as the baseline. Future changes should be isolated, tested, and recorded here after they are confirmed to work in the deployed app.
