# Project Overview: India Development Atlas

## Research motivation

Regional development in India is multidimensional. Income, poverty, education, employment, health expenditure, and electricity availability capture different aspects of economic and social conditions. The Atlas brings selected indicators into a single interface so users can inspect geographic variation, compare regions, and see where evidence is incomplete.

## Questions the tool helps users explore

- How do selected development indicators differ across states and Union Territories?
- Which regions have the highest or lowest reported value for a selected measure?
- How much regional coverage does each indicator have?
- Are two indicators associated in the available region-level observations?
- Which comparisons are limited by missing data or mismatched reference years?

## What the project does not claim

The Atlas does not create a single composite development ranking, prove causal relationships, or guarantee that all underlying observations have been independently audited. Its visualisations are exploratory and should be interpreted with the source definitions and limitations in mind.

## Portfolio skills demonstrated

- Data acquisition and organisation using CSV files.
- Data validation and missing-value handling with pandas.
- Geographic data joins and choropleth mapping with GeoJSON and Plotly.
- Interactive application development using Streamlit.
- Descriptive statistics and exploratory correlation analysis.
- Data documentation, source transparency, and manual regression testing.
- Communicating analytical limitations rather than hiding them.

## Next-stage research direction

A useful next step is a short, independently written research note based on one clearly defined question from the Atlas. Choose one indicator pair, harmonise the reference years as far as the source data allow, inspect outliers, explain limitations, and avoid causal language unless a suitable identification strategy is developed.
